# ТЗ — GitHub

## 1. Назначение

Читать и слегка править issues репозитория, не храня их копию в XOS.

## 2. Токен

Учётные данные: получить, записать, удалить `/api/github/credentials`. Проверка: `POST /api/github/connection/test`. В списке issues токен не возвращается. Пустой секрет при записи не затирает уже сохранённый, если контроллер так отличает «не прислали» от «стереть». Стереть целиком — `DELETE`.

## 3. Issues

`GET /api/github/issues` — список. `GET /api/github/issues/{number}` — карточка. `PATCH` меняет issue на стороне GitHub. Маршрута создания нет.

Виджет внешних задач использует тот же список и не имеет отдельного API.

## 4. Ошибки

Нет роли — `403`. GitHub недоступен или токен отклонён — сообщение об ошибке соединения, без тела токена в ответе.

## 5. Критерии

- [x] Токен сохраняется, проверяется и удаляется
- [x] Список и карточка issue
- [x] Правка issue уходит в GitHub
- [x] Создания issue в XOS нет
