# ТЗ — GitHub

## 1. Назначение

Читать и слегка править issues репозитория, не храня их копию в XOS.

## 2. Токен

Учётные данные: получить, записать, удалить `/api/github/credentials`. Проверка: `POST /api/github/connection/test`. Токен в ответах списка issues не возвращается.

## 3. Issues

Список, карточка по номеру, правка `PATCH` (состояние и поля, которые принимает контроллер). Создания issue в маршрутах XOS нет.

## 4. Критерии

- [x] Токен сохраняется и проверяется
- [x] Список и карточка issue
- [x] Правка issue уходит в GitHub
