# ТЗ — GitHub

## 1. Связь

Пользователь сохраняет персональный токен и при необходимости владельца и репозиторий по умолчанию. Проверка соединения не показывает токен в ответе.

## 2. Issues

Список открытых и закрытых, карточка, смена названия, текста и состояния. Запросы на слияние в список задач не попадают.

## 3. Критерии

- [x] Сохранение и удаление токена
- [x] Проверка связи
- [x] Список и правка issue
