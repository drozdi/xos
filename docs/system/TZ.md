# ТЗ — оболочка

## 1. Назначение

Дать один стол для всех модулей: войти, открыть окно, закрепить приложение, переключить страницу виджетов, найти объект, не потерять раскладку на другом устройстве.

## 2. Окна

Окно создаётся из манифеста приложения. Размер по умолчанию и минимум задаёт манифест. Окно можно таскать и менять размер. Бросок к краю ставит половину стола, в угол — четверть.

Закрытие удаляет окно из `launchHistory` и из геометрии `WIN`. Перезагрузка вкладки историю не чистит: снимок уже на сервере.

Одно приложение может запретить второе окно (`singleInstance`).

## 3. Пуск и панель

«Пуск» показывает группы доступных приложений. Недоступное по роли в список не попадает. Порядок групп фиксирован числом сортировки, подпись группы — отдельная карта. Подпись «Стандартные» относится к группе `tools` и на панели задач тоже.

Быстрый доступ — закреплённые id в настройках пользователя. Закрепление из контекстного меню списка.

Панель задач группирует открытые окна по `taskbarGroup`.

## 4. Страницы виджетов

Четыре страницы. Текущая страница — число в настройках стола. Переключение: Настройки → Виджеты или Ctrl+Alt+стрелки. Виджет не выходит за границы стола и не растягивается на панель задач.

Набор виджетов и их прямоугольники хранятся в категории `USER` снимка стола.

## 5. Поиск

Ctrl+K ищет среди приложений, списков задач, карточек доски, заметки первой базы знаний и файлов `home://`. Это клиентский сбор поверх уже существующих API, отдельного `/api/search` нет.

## 6. Настройки

Окно `settings`: профиль (`PUT /api/account`), дата и формат, макет оболочки, активное подразделение, виджеты. `shell-settings` открывает то же окно на макете.

## 7. Критерии

- [x] Окна открываются, двигаются, стыкуются к краям
- [x] Раскладка переживает перезагрузку и второй вход
- [x] Закрытое окно не возвращается из истории
- [x] Группы «Пуска» видны целиком, последний пункт списка не обрезан
- [x] Инфоблоки в «Пуске» стоят сразу после «Стандартные»
- [x] Виджеты остаются внутри стола
- [x] Игры не ходят на сервер
