# ТЗ — оболочка

## 1. Окна

Окно открывается из «Пуска», поиска или другого приложения. Позиция, размер, свёртка и разворот пишутся в `WIN`. Закрытие удаляет запись и строку из `APP.launchHistory`. Обновление страницы записи не удаляет.

Окно, отпущенное у края стола, занимает половину. У угла — четверть.

## 2. Виджеты

Виджет не попадает на панель задач и в список «Все приложения». Каталог — `USER.desktop.widgets`. У записи есть страница `page` от 0 до 3. На столе видны виджеты текущей страницы `USER.desktop.page`.

Виджет нельзя вытащить за край стола. Его можно растянуть, пока он помещается в стол. Сетка 16px включается в настройках.

Закрытие виджета выключает его в каталоге. Смена страницы окна прячет, но из каталога не выключает.

## 3. Пуск и поиск

Средняя колонка — группы приложений. В длинной группе список виртуальный. Слева — настройки, выход, перезагрузка. Справа — закреплённые.

Ctrl+K открывает поиск по имени приложения, названиям списков задач, карточкам доски, заметкам первой базы знаний и файлам `home://`.

## 4. Настройки

Вкладки: профиль, дата и время, макет оболочки, активное подразделение, виджеты. Макет и подразделение пишутся на сервер.

## 5. Критерии

- [x] Окна восстанавливаются после входа
- [x] Закрытое окно не возвращается на другом устройстве
- [x] Виджет остаётся внутри стола
- [x] Четыре страницы виджетов
- [x] Поиск Ctrl+K
