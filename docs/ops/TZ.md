# ТЗ — Ops

## 1. Назначение

Дать оператору сохранённые точки входа к Docker, VNC, БД и туннелям без хранения паролей в браузере и без произвольного SSRF на внутренние сети.

## 2. Модель

Единая сущность ссылки (`OpsLink`) с полем `kind`: `db` | `docker` | `vnc` | `tunnel`. Поля хоста, порта, учётных данных и опций зависят от kind. Список пользователя ограничен его записями (или политикой модуля).

## 3. Поведение по kind

- **Docker** — HTTP API Docker: список контейнеров, start/stop, логи. Идентификатор контейнера — hex 12–64.
- **VNC** — PHP-клиент отдаёт кадр PNG на действие; для полноценного стола Windows предпочтителен модуль RDP.
- **DB** — один запрос за вызов; опасные конструкции режет `DbStatementGuard`.
- **Tunnel** — старт/стоп процесса туннеля на стороне сервера XOS.

## 4. Безопасность

- Запрет loopback/link-local/metadata и частных адресов через `PublicHost` (если политика не расширена).
- Секреты не отдаются в GET-списках в открытом виде.
- Методы действий привязаны к id своей ссылки.
