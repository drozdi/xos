# SSH

Сохранённые подключения и терминал в окне. Пароль и ключ хранятся на сервере в зашифрованном виде.

Доступ: `ROLE_SSH`. Окно одно: `ssh`. Код: `server/src/Ssh`, `client/src/apps/ssh`.

## Сценарий

Пользователь заводит подключение: имя, хост, порт, логин и способ входа (пароль или ключ). Ключ можно сгенерировать или вставить. Открытие терминала берёт билет у API и, если задан `SSH_GATEWAY_PUBLIC_URL`, открывает WebSocket шлюза. Шлюз обменивает билет на параметры только этого подключения и сам устанавливает SSH. Без шлюза клиент читает поток `GET /api/ssh/sessions/{id}/stream`.

Билет живёт 30 секунд. Одновременно не больше трёх сессий на пользователя. `redeem` и `release` открыты без JWT и требуют заголовок `X-Gateway-Secret`.

См. [TZ.md](TZ.md), [API.md](API.md).
