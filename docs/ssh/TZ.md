# ТЗ — SSH

## 1. Назначение

Подключаться к своим серверам из рабочего стола, не вводя пароль в браузер каждый раз и не отдавая шлюзу список всех подключений.

## 2. Подключение

Поля: `name`, `host`, `port` (по умолчанию 22), `username`, `auth` (`password` или `key`). Для пароля при создании обязателен `secret`. Для ключа — `key_id` или сам ключ в `secret`. `passphrase` необязательна и ограничена 1024 символами. В ответах секрет не возвращается.

## 3. Ключи

Список своих ключей, импорт и генерация. Удаление по id. Чужой ключ к подключению не привязывается.

## 4. Сессия

Два режима.

- Шлюз. Клиент с JWT вызывает `POST /api/ssh/gateway/ticket` с `connection_id`. Ответ содержит билет и публичный URL. Процесс `ssh-gateway` вызывает `redeem` с секретом шлюза, получает расшифрованные параметры одного подключения и открывает SSH. По завершении вызывает `release`.
- Поток PHP. `POST /api/ssh/sessions` открывает сессию, `GET .../stream` отдаёт вывод, `POST .../input` пишет ввод, `DELETE` закрывает.

## 5. Критерии

- [x] CRUD подключений без отдачи секрета в списке
- [x] Импорт и генерация ключа
- [x] Билет одноразовый и привязан к пользователю и подключению
- [x] Шлюз не принимает произвольный хост из браузера
- [x] Без `SSH_GATEWAY_PUBLIC_URL` остаётся поток PHP
