# Идеи новых приложений

Не техническое задание. Улучшения уже сделанных частей — в [IMPROVEMENTS.md](IMPROVEMENTS.md). Индекс — [README.md](README.md).

| Идея | Заметки |
|------|---------|
| IMAP/SMTP inbox | Внешняя почта поверх мини-Inbox |
| Open Banking / PSD2 | Импорт выписок в IncCom без ручного CSV |
| Plugin marketplace | Каталог плагинов PKB |
| Co-editing PKB | Совместное редактирование одной заметки |
| Trello / CSV import | Импорт досок в Board |
| Board email notify | Письмо по сроку или упоминанию на карточке |
| Mobile shell app | Отдельный тонкий клиент под телефон (сейчас адаптив окна) |
| Secrets vault app | Общий сейф секретов вне SSH/RDP/GitHub |
| Monitoring dashboard | Сводка health агентов Samba / шлюзов RDP·SSH |
