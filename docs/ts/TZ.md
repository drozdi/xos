# ТЗ — TeamStorm

## 1. Назначение

Показать пространства и work item TeamStorm внутри стола, не копируя их в таблицы XOS.

## 2. Учётные данные

`GET/PUT/DELETE /api/ts/credentials`. Проверка: `POST /api/ts/connection/test`. Секрет в ответе списка не описывается. Удаление учётных данных обрывает доступ виджета и окна к тем же задачам.

## 3. Данные

`GET /api/ts/workspaces` — пространства. Внутри пространства — список work item, карточка и `PATCH`. Создания и удаления work item в маршрутах XOS нет.

Идентификаторы `workspace` и `workitem` — те, что вернул TeamStorm, не внутренние id XOS.

## 4. Критерии

- [x] Учётные данные сохраняются и удаляются
- [x] Проверка соединения
- [x] Список пространств и задач
- [x] Правка задачи уходит в TeamStorm
