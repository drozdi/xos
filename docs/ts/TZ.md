# ТЗ — TeamStorm

## 1. Назначение

Показать пространства и work item TeamStorm внутри стола, не копируя их в таблицы XOS.

## 2. Учётные данные

Токен или логин хранится на пользователя: прочитать, записать, удалить `/api/ts/credentials`. Проверка соединения: `POST /api/ts/connection/test`. Секрет на диске не описывается в ответе списка.

## 3. Данные

Список пространств, список work item пространства, карточка и правка (`PATCH`). Создание и удаление work item в маршрутах XOS нет.

## 4. Критерии

- [x] Учётные данные сохраняются и удаляются
- [x] Проверка соединения
- [x] Список пространств и задач
- [x] Правка задачи уходит в TeamStorm
