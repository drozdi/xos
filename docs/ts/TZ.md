# ТЗ — TeamStorm

## 1. Связь

Пользователь хранит базовый URL, закрытый токен и логин TeamStorm. Кнопка проверки ходит в TeamStorm от имени сервера. Токен в ответе наружу не отдаётся.

## 2. Задачи

Список пространств, затем задачи. «Мои» оставляет задачи, где пользователь исполнитель. Карточка открывается в панели: название и описание. Описание правится и сохраняется как HTML.

- [x] Сохранение и удаление связи
- [x] Проверка соединения
- [x] Список и правка задачи
