# API — задачи

Префикс `/api/todo`. Достаточно войти в систему.

| Метод | Путь | Назначение |
|-------|------|------------|
| GET, POST | `/lists` | Списки |
| GET, PUT, DELETE | `/lists/{id}` | Карточка, в ней пункты |
| POST | `/lists/{id}/share` | Открыть по почте |
| DELETE | `/lists/{id}/share/{userId}` | Закрыть |
| GET | `/users/by-email` | Найти пользователя |
| GET | `/items/due` | Пункты со сроком, query `start` и `end` |

Пункты не имеют отдельного URL: они приходят и сохраняются вместе со списком.
