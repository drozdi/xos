# ТЗ — задачи

## 1. Назначение

Хранить несколько списков задач. Пункты приходят и уходят вместе со списком: `PUT /api/todo/lists/{id}` заменяет состав.

## 2. Доступ

Достаточно входа. Операции над списком проверяют scope `todo`. Список можно открыть другому пользователю: найти `GET /api/todo/users/by-email`, затем `POST .../share`. Забрать доступ: `DELETE .../share/{userId}`.

## 3. Сроки и доска

`GET /api/todo/items/due` отдаёт пункты со сроком. Пункт может ссылаться на карточку доски. Обратная связь карточки с заметкой PKB — у доски, не у этого модуля.

## 4. Критерии

- [x] CRUD списков
- [x] Пункты сохраняются вместе со списком
- [x] Шаринг списка пользователю
- [x] Лента пунктов со сроком
