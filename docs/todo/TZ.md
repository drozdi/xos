# ТЗ — задачи

## 1. Назначение

Хранить несколько списков задач. Пункты списка приходят вместе со списком, отдельного CRUD пункта в маршрутах нет.

## 2. Доступ

Список можно открыть другому пользователю по email (`users/by-email`, затем `share`). Забрать доступ: `DELETE .../share/{userId}`.

## 3. Сроки

`GET /api/todo/items/due` отдаёт пункты со сроком. Его читают поиск Ctrl+K и виджет «Сегодня».

## 4. Критерии

- [x] CRUD списков
- [x] Шаринг списка пользователю
- [x] Лента пунктов со сроком
