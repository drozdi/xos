# ТЗ — задачи

## 1. Список

Название, цвет, текст в Markdown и пункты: текст, сделано, срок, порядок. Владелец правит всё. Получатель share читает или тоже правит.

## 2. Срок

Пункт со сроком виден в календаре. Если срок в пределах двух часов вперёд или суток назад, оболочка показывает уведомление. Виджет «Сегодня» берёт пункты текущего дня.

## 3. Критерии

- [x] CRUD списков
- [x] Пункты внутри списка
- [x] Share по почте
- [x] Сроки в календаре и в ленте
