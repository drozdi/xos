# Задачи

Списки дел с пунктами, сроком и цветом. Список можно отдать другому пользователю.

Доступ к окну есть у любого вошедшего. Отдельной роли `ROLE_TODO` нет.

Сроки на ближайшие сутки попадают в ленту оболочки и в виджет «Сегодня».

Код: `server/src/Todo`, `client/src/apps/todo`.

См. [TZ.md](TZ.md), [API.md](API.md).
