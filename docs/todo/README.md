# Задачи

Списки дел и общий доступ к списку. Пункты живут внутри списка: отдельного CRUD пункта нет, список сохраняется целиком.

Окно открыто любому вошедшему: модуль не в списке защищённых. Права на списки — scope claimant `todo`. В манифесте окно называется «Заметки», id — `todo`. Код: `server/src/Todo`, `client/src/apps/todo`.

Привычки — соседнее окно без своих таблиц: [habits/README.md](../habits/README.md).

## Сценарий

Пользователь ведёт несколько списков. Пункт можно связать с карточкой доски (`board_card_id`). Срок попадает в `GET /api/todo/items/due`: его читают поиск и виджет «Сегодня». Список открывается другому пользователю по email.

См. [TZ.md](TZ.md), [API.md](API.md).
