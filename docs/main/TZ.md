# ТЗ — администрирование

## 1. Пользователи

Список, создание, карточка: имя, почта, alias, пароль, роли, группы, подразделения. Нельзя удалить себя. Пароль меняется только вместе с проверкой текущего, если это своя учётка, и администратором — для чужой.

## 2. Группы и подразделения

Группа связывает пользователей и набор прав. Подразделение — дерево организации. Активное подразделение пользователя фильтрует списки устройств. Оно хранится в user-data, переключается в настройках оболочки.

## 3. Права

Claimant описывает модуль и биты `can_*`. Источник для проверки запроса — `setting.json`. Экран «Доступные права» читает БД. Команда `main:claimant:sync` переносит файл в БД. При старте API процесс сверяет их и пишет предупреждение, если есть расхождение.

## 4. Журнал

Экран аудита показывает действия администраторов. Нужно право чтения `main.audit`.

## 5. Критерии

- [x] CRUD пользователей, групп, подразделений, claimants
- [x] Роли защищённых модулей выдаются из карточки
- [x] Активное подразделение влияет на списки Device
