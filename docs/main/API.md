# API — администрирование

Префикс `/api/main`. Нужна роль `ROLE_MAIN`, кроме выбора пользователей там, где метод явно открыт модулю.

Списки `POST .../list` принимают фильтр в теле. Карточка: `GET /{id}`, создание `POST /`, правка `PUT /{id}`, удаление `DELETE /{id}`.

| Префикс | Методы сверх CRUD |
|---------|-------------------|
| `/api/main/user` | `POST /list`, `POST /filter`, смена пароля и ролей в теле карточки |
| `/api/main/group` | `POST /list`, `POST /filter` |
| `/api/main/ou` | `POST /list`, выбор для селектов |
| `/api/main/claimant` | список и карточка правила |
| `/api/main/audit` | чтение журнала |
| `/api/main/file` | upload, метаданные, скачивание |

Загрузка файла описана в [../API.md](../API.md).
