# API — склад и имущество

Роль `ROLE_ASSETS`. У каждого каталога один и тот же набор:

| Метод | Путь | Назначение |
|-------|------|------------|
| POST | `{префикс}/list` | Список |
| POST | `{префикс}/` | Создать |
| GET | `{префикс}/{id}` | Карточка |
| PUT | `{префикс}/{id}` | Правка |
| DELETE | `{префикс}/{id}` | Удаление |

Префиксы:

| Каталог | Префикс |
|---------|---------|
| Склад | `/api/assets/warehouse` |
| Автопарк | `/api/assets/fleet` |
| Контрагенты | `/api/assets/parties` |
| Договоры | `/api/assets/contracts` |
| Помещения | `/api/assets/rooms` |
| Программы | `/api/assets/software` |
