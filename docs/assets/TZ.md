# ТЗ — склад и имущество

## 1. Общий вид

Шесть каталогов устроены одинаково: список и карточка. Поля свои у склада, транспорта, контрагента, договора, помещения и программного пакета.

## 2. Подразделение

Если у пользователя выбрано активное подразделение, список показывает записи этого OU.

## 3. Устройство

Id складской позиции можно записать на устройстве. Обратной ссылки в карточке склада нет.

## 4. Критерии

- [x] CRUD всех шести каталогов
- [x] Фильтр по подразделению
- [x] Поле связи на устройстве
