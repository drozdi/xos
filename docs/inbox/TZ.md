# ТЗ — почта

## 1. Назначение

Отправить сообщение другому пользователю XOS, прочитать его и удалить у себя.

## 2. Сообщение

Список, создание, карточка, отметка прочитанным, удаление. Отдельных папок, вложений и черновиков нет.

Прочитанность — `POST /api/inbox/messages/{id}/read`, не правка всего письма. Отдельного `PUT` сообщения нет.

## 3. Кто видит

Список возвращает сообщения текущего пользователя. Чужое сообщение по id недоступно. Без `ROLE_INBOX` окон нет.

## 4. Критерии

- [x] Список, отправка, чтение, отметка прочитанным, удаление
- [x] Без роли `ROLE_INBOX` окна нет
- [x] IMAP не входит в этот модуль
