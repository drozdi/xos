# ТЗ — почта

## 1. Письмо

Тема, текст Markdown, отправитель и получатель по почте или id. Список делится на входящие и отправленные. Непрочитанное помечено, пока его не откроют.

## 2. Вложение

Файл уходит в общее хранилище модуля `inbox`. В текст добавляется ссылка на него. Отдельной таблицы вложений нет.

## 3. Несколько окон

Открытие письма и отправка сбрасывают кэш списка, поэтому второе окно почты видит то же состояние.

## 4. Критерии

- [x] Список входящих и отправленных
- [x] Создание и удаление
- [x] Отметка прочитанного
- [x] Вложение ссылкой
- [x] Непрочитанные в ленте оболочки
