# ТЗ — почта

## 1. Назначение

Отправить сообщение другому пользователю XOS, прочитать его и удалить у себя.

## 2. Сообщение

Список входящих, создание, карточка, отметка прочитанным, удаление. Отдельных папок, вложений и черновиков в маршрутах нет.

Прочитанность — `POST /api/inbox/messages/{id}/read`, не правка всего сообщения.

## 3. Критерии

- [x] Список, отправка, чтение, отметка прочитанным, удаление
- [x] Без роли `ROLE_INBOX` окна нет
