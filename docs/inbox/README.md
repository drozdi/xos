# Почта

Внутренние сообщения между пользователями XOS. Внешнего IMAP нет: это отдельная идея в [APP_IDEAS.md](../APP_IDEAS.md).

Доступ: `ROLE_INBOX`. Окна `inbox` (список) и `inbox-message` (карточка). Код: `server/src/Inbox`, `client/src/apps/inbox`, `client/src/apps/inbox-message`.

## Сценарий

Пользователь открывает входящие, пишет сообщение другому пользователю, открывает карточку и отмечает прочитанным. Удаление убирает сообщение у того, кто удалил. Папок, вложений и черновиков нет. Виджет сроков показывает непрочитанные рядом с карточками и задачами.

См. [TZ.md](TZ.md), [API.md](API.md).
