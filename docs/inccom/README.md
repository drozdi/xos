# Доходы и расходы

Счета, категории операций, операции, переводы между счетами, номенклатура и чеки ФНС.

Доступ: `ROLE_INCCOM`. Код: `server/src/IncCom`, `client/src/apps/inccom`. Префикс API сохраняет регистр `IncCom`.

Одно окно `inccom` закрывает счета и журнал. Отдельных окон на каждую сущность нет.

## Сценарий

Пользователь ведёт счета, категории операций и номенклатуру. Операция относится к счёту. Перевод связывает два счёта. Чек: учётные данные ФНС, предпросмотр, загрузка чека в операцию и разбор позиций. Секрет ФНС шифруется и в ответах не отдаётся.

Свой вход: `/api/IncCom/auth/login` и refresh `/api/IncCom/token/refresh` (cookie `xos_app_refresh`). Регистр `IncCom` в пути обязателен. Стол входит общим `/api/login`.

См. [TZ.md](TZ.md), [API.md](API.md).
