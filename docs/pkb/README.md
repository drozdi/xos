# База знаний

Хранилище заметок (vault): дерево файлов, поиск, граф, обратные ссылки, участники, экспорт и закладки.

Доступ: `ROLE_PKB`. Код: `server/src/Pkb`, `client/src/apps/pkb`.

## Сценарий

Пользователь открывает хранилище, пишет markdown и связывает заметки через `[[Название]]`. Поиск ищет по индексу, граф строится по этим ссылкам. Участнику выдаётся роль на хранилище. Экспорт отдаёт архив. Закладки — отдельный список путей.

Документация продукта лежит в том же хранилище: `Notes/Docs` и `Notes/Apps/<модуль>`. Её пишет `php bin/console xos:seed-project` из папки `docs/`.

Индекс пересобирается `POST /api/pkb/vaults/{id}/index/rebuild`. Статус — `GET .../index/status`.

См. [TZ.md](TZ.md), [API.md](API.md).
