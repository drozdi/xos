# База знаний

Хранилища заметок (vault): файлы, поиск, граф, обратные ссылки, участники, экспорт и закладки.

Доступ: `ROLE_PKB`. Код: `server/src/Pkb`, `client/src/apps/pkb`.

Заметка — файл в дереве хранилища. Индекс строится отдельно и пересобирается по запросу.

См. [TZ.md](TZ.md), [API.md](API.md).
