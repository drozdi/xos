# ТЗ — база знаний

## 1. Назначение

Держать одну или несколько баз заметок. У хранилища есть владелец и участники. Заметки лежат файлами, связи между ними считает индекс.

## 2. Файлы

Дерево, чтение и запись содержимого, загрузка, папка, переименование, удаление. Это не проводник: пути внутри vault, префикс `/api/pkb/vaults/{id}/files`.

## 3. Индекс

Список заметок, поиск, замена по поиску, заметка по заголовку, обратные ссылки, граф. Статус индекса и пересборка — отдельные методы. Поиск Ctrl+K берёт первую доступную базу.

## 4. Участники и обмен

Приглашение, смена роли, удаление участника. Экспорт хранилища и remote-sync — отдельные методы. Закладки пользователя на vault: GET и PUT `/bookmarks`.

## 5. Критерии

- [x] CRUD хранилища
- [x] Дерево файлов и запись заметки
- [x] Поиск, граф, обратные ссылки
- [x] Пересборка индекса
- [x] Участники, экспорт, закладки
