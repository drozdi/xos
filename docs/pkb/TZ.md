# ТЗ — база знаний

## 1. Хранилище

У хранилища имя и корень в проводнике. Участник бывает владельцем, редактором или читателем. Экспорт — ZIP. Удалённая копия отправляется на `remote_sync_url`.

## 2. Заметки

Режимы правки, чтения и исходника. Ссылки `[[название]]`, теги, вложения. Обратные ссылки и граф строятся по индексу. Поиск по тексту и замена по хранилищу.

Кнопка «Сегодня» создаёт `Daily/ГГГГ-ММ-ДД.md`. Кнопка «Встреча» пишет шаблон `Templates/Встреча.md`. Кнопка «Читатель» приглашает email с ролью reader.

## 3. Индекс

Статус индекса и пересборка. Пока индекс устарел, поиск может не видеть новый файл.

## 4. Критерии

- [x] CRUD хранилища и участников
- [x] Дерево и содержимое файлов
- [x] Поиск, граф, обратные ссылки
- [x] Экспорт и remote sync
- [x] Заметка дня, шаблон встречи, приглашение читателя
