# Идеи улучшений XOS

> 2026-10-15. Не ТЗ. Крупный внешний бэклог по-прежнему в [APP_IDEAS.md](APP_IDEAS.md): IMAP/SMTP, Open Banking, co-edit PKB, marketplace, импорт Trello, email по карточкам.

Список ниже из этого файла выполнен.

## Сделано

- Кэш `user_app_data`, поиск в Пуске, сетка виджетов, синхронизация стикеров и prefs
- Ресайз виджетов в рамке стола, snap окон к половине и четверти
- Погода, часы, ежедневные напоминания, лента сроков и Inbox, виджет «Ближайшее»
- Ленивая загрузка манифестов (`import.meta.glob` без eager)
- Пагинация `page`/`size`: `App\Http\PageQuery` (legacy `limit`/`offset` тоже читается)
- Проверка дрейфа claimants на первом API-запросе процесса (`main:claimant:sync`)
- Виртуализация длинной группы в «Все приложения» (`react-window`, больше 20 пунктов)
- Бюджет бандла в CI: `client/scripts/check-bundle-size.mjs` (8 МБ на один js)
- Четыре стола виджетов, Ctrl+Alt+стрелки
- Поиск Ctrl+K: приложения, списки задач, карточки, заметка PKB, файлы `home://`
- Упоминание `@alias` в комментарии карточки попадает в ленту
- WIP колонки (`board.wipLimits`), шаблоны карточек, ссылка GitHub/TeamStorm
- PKB: заметка дня, шаблон «Встреча», приглашение читателя
- Повтор события календаря (день / неделя, отдельные записи)
- Виджет «Сегодня»: задачи и серия привычек; просрочка уже в ленте
- Вложение Inbox через upload (`module=inbox`); списки писем инвалидируются между окнами
- IncCom: CSV `дата;сумма;комментарий`, бюджет месяца и полоска расхода
- Связка устройства и позиции склада: поле на карточке устройства
- Виджеты «Уроки», «Внешние задачи», «Файлы»
- `iblock:catalog-stub` — конфиг каталога поверх общего ContentCatalog
- `app:openapi:dump` — `server/var/openapi.json` из маршрутов
- Тесты: WIN при закрытии, границы виджета `fitRectToDesktop`
