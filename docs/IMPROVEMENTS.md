# Идеи улучшений

Не техническое задание. Новые приложения — в [APP_IDEAS.md](APP_IDEAS.md).

| Область | Идея |
|---------|------|
| API | Схемы тел в OpenAPI, не только список путей |
| Списки | Виртуализация таблиц каталогов, не только меню «Пуск» |
| Device / Assets | Настоящая связь устройства и складской позиции в базе, не текстовый id |
| Календарь | Один ряд повторов вместо нескольких отдельных событий |
| Доска | Письмо по карточке, импорт Trello |
| PKB | Совместное редактирование и каталог плагинов |
| Inbox | Внешняя почта IMAP/SMTP |
| IncCom | Выписка банка, не только CSV |
