# Идеи улучшений

Не техническое задание. Новые приложения — в [APP_IDEAS.md](APP_IDEAS.md).

| Область | Идея |
|---------|------|
| API | Схемы тел в OpenAPI, не только список путей |
| Списки | Виртуализация длинных таблиц каталогов |
| Календарь | Один ряд повторов вместо отдельных событий |
| Доска | Письмо по карточке, импорт Trello, WIP-лимиты на сервере |
| PKB | Совместное редактирование, каталог плагинов, conflict UI |
| Inbox | Внешняя почта IMAP/SMTP |
| IncCom | Банковская выписка / Open Banking |
| Samba | Ротация секрета агента без zip; provision из UI; метрики heartbeat |
| RDP | Звук в браузере, диски, удалённые guacd-узлы |
| Ops/VNC | Поток вместо покадрового PNG |
| Оболочка | Не терять prefs приложений при contentKey refresh |
| SSH/SFTP | Единый UX с Ops links |
