# RDP

Удалённый рабочий стол Windows в окне. Пароль хранится на сервере. Браузер получает только одноразовый билет.

Доступ: `ROLE_RDP`. Админка сетей: `ROLE_RDP_ROOT` или `ROLE_ROOT`. Код: `server/src/Rdp`, `client/src/apps/rdp`, `rdp-gateway`, контейнер `guacd`.

## Сценарий

Пользователь сохраняет подключение: хост, порт, пользователь, домен и пароль. Публичный адрес разрешён. Внутренний адрес разрешён, только если он входит в сеть, выданную группе или роли пользователя. Открытие сессии берёт билет на 30 секунд. Шлюз обменивает билет на параметры и открывает RDP через локальный guacd. В инструкцию подключения подставляется уже проверенный IP, не исходное имя.

`redeem` и `release` открыты без JWT и требуют заголовок `X-Gateway-Secret`. guacd наружу не публикуется.
