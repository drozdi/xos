# ТЗ — привычки

## 1. Список

Привычка — название и цвет. День отмечается в сетке. Серия считается по непрерывным отметкам и пишется в `habits.streaks`.

## 2. Связь с задачами

Отдельного сервера нет. Доступ такой же, как у списков дел: любой вошедший.

## 3. Критерии

- [x] Отметка дня
- [x] Серия сохраняется между входами
- [x] Число серии видно на виджете «Сегодня»
