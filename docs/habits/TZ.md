# ТЗ — привычки

## 1. Назначение

Отмечать, в какие дни привычка выполнена, и считать текущую серию без отдельного модуля на сервере.

## 2. Хранение

Ключ user-data `habits.streaks`. Значение — JSON клиента. Сервер не проверяет календарь и не сбрасывает серию сам: это делает окно при открытии.

## 3. Связь с задачами

Окно открыто любому вошедшему, как и задачи. Своего claimant нет.

## 4. Критерии

- [x] Отметка дня пишется в user-data
- [x] Серия видна в окне и в виджете «Сегодня»
- [x] Отдельных таблиц и маршрутов нет
