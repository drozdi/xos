# Привычки

Отметки дней и серия. Отдельной роли, таблиц и маршрутов нет. Окно `habits` открывается вместе с задачами любому вошедшему.

Серия лежит в user-data `habits.streaks`. Сервер не пересчитывает дни: окно само пишет JSON и при открытии обновляет серию. Виджет «Сегодня» показывает наибольшее число из этого ключа.

Код: `client/src/apps/habits`, `client/src/features/habits`.

См. [TZ.md](TZ.md), [API.md](API.md).
