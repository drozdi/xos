# ТЗ — устройства

## 1. Устройство

Карточка: название, код, тип, описание, учёт, места, ремонты, свойства, лицензии, изображения. Тип задаёт набор свойств. Подразделение записи совпадает с активным OU пользователя, если оно выбрано.

## 2. Справочники

Типы устройств, свойства, типы комплектующих, программы и типы программ, лицензии и ключи. Справочник правится отдельным окном и подставляется в карточку.

## 3. Комплектующие

Отдельный список деталей, привязанных к устройству или складу комплектующих.

## 4. Критерии

- [x] CRUD устройства и справочников
- [x] Фильтр по подразделению
- [x] Файлы изображений через upload модуля `device`
