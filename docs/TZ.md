# ТЗ — продукт XOS

## 1. Назначение

XOS — рабочий стол в браузере. Пользователь входит, видит стол, панель задач и меню «Пуск», открывает приложения в окнах. Данные приложений хранятся на сервере и подтягиваются на другое устройство.

## 2. Состав

| Слой | Где | Что делает |
|------|-----|------------|
| API | `server/` | Symfony, JWT, модули приложений |
| Оболочка | `client/src/core/` | Окна, Пуск, настройки, синхронизация сессии |
| Приложения | `client/src/apps/` | Окна рабочего стола |

Приложения описаны отдельно: README, ТЗ и API в своей папке.

## 3. Вход и права

- Вход: `POST /api/login`, обновление токена: `POST /api/token/refresh`.
- Защищённый модуль требует роль `ROLE_<МОДУЛЬ>` и scope `can_*`.
- Каталог прав живёт в `setting.json` модулей. Копия для экранов администрирования — в БД. Если они разъехались, процесс пишет предупреждение в лог. Синхронизация: `php bin/console main:claimant:sync`.

## 4. Оболочка

- Окна перетаскиваются. Бросок к краю стола ставит окно на половину, в угол — на четверть.
- Виджеты остаются внутри рабочего стола, растягиваются только в этих границах.
- Четыре страницы виджетов. Переключение: Настройки → Виджеты или Ctrl+Alt+стрелки.
- Поиск Ctrl+K ищет приложения, списки задач, карточки доски, заметку в первой базе знаний и файлы `home://`.
- Закрытие окна убирает его из истории запуска и из сохранённой геометрии. Обновление вкладки историю не стирает.

## 5. Общие хранилища

| Хранилище | Зачем |
|-----------|--------|
| `/api/desktop-state` | Настройки USER/APP/WIN и последний путь проводника |
| `/api/user-data` | Произвольные prefs приложений (`code` + JSON) |
| `/api/settings` | Отдельные ключи настроек |
| `/api/main/file/upload` | Файлы модулей из белого списка |

Списки новых методов читают `page` и `size`. Старые списки по-прежнему принимают `limit` и `offset`. Разбор обоих форматов: `App\Http\PageQuery`.

## 6. Критерии приёмки продукта

- [x] Вход и рабочий стол с окнами
- [x] Меню «Пуск», панель задач, настройки
- [x] Сессия окон синхронизируется между устройствами
- [x] Модули закрыты ролями
- [x] Виджеты не уезжают за край стола
