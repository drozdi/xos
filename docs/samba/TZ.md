# ТЗ: серверы Samba, фаза 1

Сервер принадлежит пользователю. Роль процесса — контроллер домена AD. Значение NT4 хранится как будущее и API его не принимает. Шары на этой фазе только признак «раздаёт шары», без настройки путей.

Доступ к чужому серверу — строка выдачи с маской прав: просмотр, шары, каталог, службы, управление. Журнал и передача владения не выдаются. Без `ROLE_SAMBA` выдача не открывает API. Получатель при удалении теряет выдачу, сервер остаётся.

Владение передаёт владелец, `ROLE_SAMBA_ROOT` или `ROLE_ROOT`. Удаление владельца с серверами отвечает «сначала передайте серверы».
