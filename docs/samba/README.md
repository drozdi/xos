# Samba

Управление контроллерами домена Samba AD из рабочего стола XOS: карточка сервера, агент на DC, снимок каталога, команды домена, шары и импорт пользователей, групп и подразделений из модуля Main.

Доступ: `ROLE_SAMBA`. Код: `server/src/Samba`, окно `client/src/apps/samba-servers`, агент `server/agent`.

## Состав

| Часть | Где | Роль |
|-------|-----|------|
| Центр | API и окно «Серверы Samba» | Карточки, права, очередь, bundle, снимок каталога, правила импорта |
| Агент | Хост Samba DC | Очередь, `samba-tool` / `ldb*`, шары, свой WebSocket |
| CA | `SAMBA_AGENT_CA_FILE` | PEM попадает в zip как `ca.pem`. Без файла bundle отвечает 503 |

## Окно

Вкладки карточки: **Общее**, **Установка**, **Домен**, **Шары**, **Конфиг**. Содержимое вкладок не сбрасывается при смене ширины экрана.

Вкладка «Домен» открывает дерево по снимку каталога. У подразделения, пользователя и группы свои вкладки. У пользователя можно сменить пароль. В списках сначала показывается `displayName`, у группы — описание. Все LDAP-атрибуты объекта — на отдельной вкладке.

Вкладка **Импорт** (нужно право `manage`) переносит отмеченные записи Main. Подробности — [TZ.md](TZ.md).

## Агент

1. Создать сервер. Токен агента генерируется сам. Кнопка «Сменить токен» пишет новый; на уже установленный агент он попадает только после новой установки.
2. В карточке указать **адрес агента** `http://хост:8765`. Пустой адрес значит, что агент сам забирает очередь.
3. Вкладка «Установка»: curl с HTTP Basic скачивает zip (`install.sh`, `agent.ini`, `ca.pem`). В ini уже лежат токен и `listen = 0.0.0.0:8765`.
4. На DC: PHP CLI 8.1+ с curl, json, sodium, openssl (php-fpm не нужен), Samba AD, `samba-tool`, `ldbmodify`, `ldbsearch`, systemd.
5. `sudo sh install.sh` переносит файлы в каталог агента и поднимает `xos-agent`.

Агент слушает WebSocket и `POST /run`. Центр подключается по адресу из карточки и передаёт токен установки. Если адреса нет, команда уходит в локальный хаб `samba:agent-hub` или остаётся в long-poll. Очередь и `POST /result` общие для всех способов.

На Zentyal шары часто в `/home/samba/shares`. Корень задаётся `share_roots` в `agent.ini`.
