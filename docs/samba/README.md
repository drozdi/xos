# Samba

Серверы контроллера домена в группе «Администрирование». Агента на этой фазе нет: сервер только регистрируется, доступ выдаётся другим пользователям.

Доступ: `ROLE_SAMBA`. Код: `server/src/Samba`, `client/src/apps/samba-servers`, агент — `server/agent`.

## Сценарий

Владелец создаёт сервер: имя, описание, контроллер домена с шарами или без них, часовой пояс. Статус «новый». Он выдаёт другому пользователю с `ROLE_SAMBA` просмотр и другие права, кроме журнала. Журнал команд читает только владелец. Удаление пользователя, у которого есть серверы, отклоняется: сначала нужно передать владение.

См. [TZ.md](TZ.md), [API.md](API.md).
