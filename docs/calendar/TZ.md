# ТЗ — календарь

## 1. Назначение

Держать несколько календарей пользователя и чужие календари, которыми поделились. Событие принадлежит календарю и попадает в выборку за интервал.

## 2. Доступ

Календарь можно открыть пользователю (`share` / `unshare`) и группе (`share-group`). Пользователя ищут по email, группу — по коду.

## 3. События

Создание, правка и удаление — отдельные методы. Выборка за период: `POST /api/calendar/events/query`. Повторы, если они есть, приходят отдельными событиями: одного ряда повтора в API нет. Это отмечено в [IMPROVEMENTS.md](../IMPROVEMENTS.md).

## 4. Вход модуля

Свой login и refresh. Стол входит через общий `/api/login`.
