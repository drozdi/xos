# ТЗ — проводник

## 1. Назначение

Дать пользователю свои папки и файлы внутри XOS: создать, переименовать, копировать, переместить, удалить в корзину, скачать, открыть содержимое, собрать и разобрать архив.

## 2. Диски

Диск — корень, который видит проводник. Список: `GET /api/explorer/disks`. Создание и удаление — отдельные методы. Конфигурация клиента (что показывать) — `GET /api/explorer/config`.

Путь в запросах — параметр конкретного метода (`path` и родственные поля). Проводник не ходит в произвольную файловую систему сервера вне разрешённых корней.

## 3. Папки и файлы

Список каталога, дерево и карточка info разделены. Скачивание и чтение содержимого — разные методы: download отдаёт файл, content читает и записывает текст.

Загрузка — `multipart` на `/api/explorer/upload`. Новая папка — `/api/explorer/folder`.

Удаление кладёт объект в корзину (`DELETE /api/explorer/item`). Восстановление и очистка корзины — отдельные методы.

## 4. Архивы

Просмотр состава, упаковка и распаковка: `/api/explorer/archive/list|pack|unpack`.

## 5. Окна просмотра

notepad, code, markdown, pdf, office, image, audio, map, diff, open-picker и save-picker — клиентские окна. Они берут байты через download/content и не добавляют маршрутов.

## 6. Критерии

- [x] Список, дерево, создание папки, переименование, копирование, перенос
- [x] Загрузка и скачивание
- [x] Корзина: список, восстановление, очистка
- [x] Архив: список, упаковка, распаковка
- [x] Последний путь переживает перезапуск стола
