# Проводник

Файлы пользователя: диски, список, дерево, просмотр, архив, корзина.

Доступ: `ROLE_EXPLORER`.

Окна: сам проводник и средства просмотра (текст, код, картинка, pdf, офис, аудио, видео, карта, diff, архиватор). Диалоги открытия и сохранения в «Пуске» скрыты.

Последний путь — `explorer.last_path`. Закрепления — `explorer.pins`. Виджет «Файлы» их показывает.

Код: `server/src/Explorer`, `client/src/apps/explorer*`, `client/src/features/explorer`.

См. [TZ.md](TZ.md), [API.md](API.md).
