# Проводник

Файлы пользователя: диски, дерево, просмотр, корзина, архивы. Окна просмотра (текст, код, pdf, офис, картинка, звук, карта, сравнение) открываются из проводника и не являются отдельным API.

Код: `server/src/Explorer`, `client/src/apps/explorer*`.

Последний путь хранится в снимке стола, чтобы виджет проводника и окно открывались там же.

См. [TZ.md](TZ.md), [API.md](API.md).
