# ТЗ — школа

## 1. Структура

Параллель, класс, предмет, участники (учитель, тьютор, ученик). Класс можно перевести и выпустить. Предмету назначаются учителя.

## 2. Расписание

У события есть начало, конец, название и файлы. Ученик читает свой класс. Редактор класса добавляет, меняет и удаляет события, выбирает подгруппу и учителя. Учитель видит свои события за интервал и сохраняет урок с файлами.

Шаблоны уроков — отдельный список.

## 3. Домашние задания

Список работ класса. Файлы скачиваются по id.

## 4. Доступ семьи

У класса есть шары: другой пользователь видит расписание. Это не отдельное приложение.

## 5. Критерии

- [x] CRUD классов, параллелей, предметов
- [x] Расписание ученика и редактора
- [x] События учителя и файлы
- [x] Виджет уроков на сегодня
