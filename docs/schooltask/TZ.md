# ТЗ — школа

## 1. Назначение

Вести классы, предметы, учителей и учеников, собирать расписание и отдавать домашние задания.

## 2. Классы и параллели

Класс принадлежит параллели. Параллель можно перевести и выпустить (`promote`, `graduate`). То же доступно для одного класса и для всех классов сразу (`classes/promote-all`).

В карточке класса выбираются предметы, тьюторы и ученики. Списки для селектов: `.../options`. Классом можно поделиться: `GET/POST/DELETE .../classes/{id}/shares`.

Участники подтягиваются командой синхронизации `POST /api/schooltask/members/sync`.

## 3. Предметы

Справочник предметов. У предмета есть учителя: `GET /api/schooltask/subjects/teachers/options`.

## 4. Расписание

Три вида одного календаря:

- ученик читает события класса;
- редактор добавляет, меняет и удаляет события, видит подгруппы и учителей;
- учитель видит свои события, прикладывает файлы и импортирует их.

Шаблоны уроков: `GET /api/schooltask/calendar/lesson-templates`. Файл урока скачивается через `GET /api/schooltask/files/{id}/download`.

## 5. Домашние задания

`GET /api/schooltask/homework` — лента заданий. Отдельного CRUD в маршрутах нет.

## 6. Вход модуля

Есть `POST /api/schooltask/auth/login` и refresh. Оболочка XOS использует общий `/api/login` и роль `ROLE_SCHOOLTASK`.
