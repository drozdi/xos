# ТЗ — доска

## 1. Назначение

Вести канбан: пространство, внутри доски, колонки и карточки. Карточка едет между колонками, получает исполнителей и метки.

## 2. Участники

И пространство, и доска имеют участников с ролью на этой доске. Приглашение, смена роли и удаление — отдельные методы. Это не подразделения Main.

## 3. Карточка

Создаётся в колонке. Перенос: `PUT /api/board/cards/{id}/move`. Исполнители и метки задаются целиком, заменой списка.

Чеклист принадлежит карточке, пункт — чеклисту. Комментарии и вложения тоже на карточке. Вложение можно загрузить или импортировать. Скачивание — по id вложения.

Срок карточки отдаёт `GET /api/board/cards/due` (виджет и поиск). Связанные карточки: `GET /api/board/cards/linked`.

## 4. Лента

Активность доски, инкремент изменений, realtime и events — четыре чтения. Если задан публичный URL Mercure, клиент слушает хаб, а `/events` остаётся запасным опросом раз в 5 секунд. Поиск: `GET /api/board/search` (`page`, `limit` 1–100, `sort`, `order`). Фильтр карточек одной доски: `GET /api/board/boards/{id}/cards`.

## 5. Критерии

- [x] CRUD пространства, доски, колонки, карточки, метки
- [x] Перенос карточки и порядок колонок
- [x] Участники пространства и доски
- [x] Чеклисты, комментарии, вложения
- [x] Лента изменений и поиск
- [x] Доска не фильтруется подразделением
